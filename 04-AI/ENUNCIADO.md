# Ejercicio 2: Código con AI (20 min)

Puedes usar la AI que prefieras. Elige **uno** y constrúyelo (la API del ejercicio 1 debe estar corriendo en `http://localhost:8080`):

- (a) Un script que consulte `/health` y `/users` y muestre código HTTP y tiempo de respuesta.
- (b) Un test automatizado para `POST /orders` (caso válido, sin items, producto inexistente, etc.).
- (c) Un script que lea un CSV de resultados de pruebas (`test,status,duration_ms`) y muestre % de pass/fail y los 3 más lentos.

Después: explícanos el código línea por línea y haremos un cambio en vivo.
