# La mejor racha

Andrés tiene una tienda en línea y anota cada día la ganancia neta: un número positivo si ganó dinero y uno negativo si perdió. Para su reporte anual quiere saber cuál fue su mejor racha, es decir, el mayor total que se puede obtener sumando días **consecutivos**. La racha debe tener al menos un día.

## Entrada

Cada línea representa un caso de prueba. Empieza con un entero `N` (1 ≤ N ≤ 100 000), la cantidad de días, seguido de `N` enteros con la ganancia de cada día. El valor absoluto de cada ganancia no supera 1 000 000 000. La entrada termina con el fin de archivo (EOF).

## Salida

Para cada caso de prueba imprime en una línea la suma de la mejor racha.

## Ejemplo de entrada

```
8 -2 1 -3 4 -1 2 1 -5
3 -1 -2 -3
4 2 3 -10 4
1 7
```

## Ejemplo de salida

```
6
-1
5
7
```
